Two-factor codes

PHV has TOTP (the six-digit codes of authenticator apps) and QR codes built in: totp_secret(), qr_svg() and totp_verify(), which tolerates a little clock drift and tells you which time step matched so the same code cannot be accepted twice.

Scan this with Google Authenticator, 1Password, Authy or similar, then enter the code it shows.
