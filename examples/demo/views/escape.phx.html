What does not compile

Putting a plain string where escaping cannot protect it is an error, not a warning:

$ phx check bad.phx
error: a URL attribute cannot start with an unchecked value
 --> bad.phx:4:14
  |
4 | <a href="<?= $url ?>">this link</a>
  |              ^^^^
  = note: use `safe_url($url)`, which only allows http(s), mailto, tel and relative URLs (blocks `javascript:`); `escape()` does not make a URL safe

The same goes for unquoted attributes, event handlers such as onclick, style and plain strings inside <script>.
